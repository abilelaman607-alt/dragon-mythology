# Драконы в мифологии

Учебный проект — сайт про драконов из разных мифологий.

## Ссылка на сайт
https://abilelaman607-alt

## Страницы
- index.html — Главная
- task1.html — О драконах
- task2.html — Виды (таблица)
- task3.html — Галерея
- task4.html — Контакты (форма)

## Что использовано
- HTML: семантические теги, таблица, форма, списки, картинки
- CSS: 3 файла — base, layout, resp
- Flexbox и CSS Grid
- Позиционирование: relative, absolute, fixed
- Media queries: 768px и 480px
- Bootstrap 5: сетка, кнопки, формы, navbar
